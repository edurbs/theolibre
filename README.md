# TheoLibre

**TheoLibre** is an independent, source-available desktop application for reading digital publications.

It is designed to provide a native Linux desktop experience for personal and other permitted noncommercial study and reading of publications in supported file formats, including `.jwpub` files.

TheoLibre is written in **Java** and **JavaFX**.

## Features

* Open and read `.jwpub` files
* Browse publication content locally
* Search within locally available publications
* Manage a local publication library
* Download media referenced by supported publications
* Play downloaded audio and video locally
* Native Linux desktop application
* No proprietary JW Library code
* No bundled third-party publications or media
* No content hosted or mirrored by TheoLibre servers
* No account with JW.ORG or JW Library is required to read local files

## `.jwpub` Compatibility

TheoLibre supports opening and reading **`.jwpub` files**, a publication file format used by **JW Library®**.

TheoLibre is designed to read `.jwpub` files that the user has independently obtained and is entitled to use.

The ability to open or process the `.jwpub` file format does not imply any affiliation with, endorsement by, or ownership of the format or the content stored within such files.

TheoLibre does not distribute `.jwpub` publication files as part of the application or repository.

## Media Downloads

Some `.jwpub` files contain references to associated media resources, including video and audio files.

TheoLibre may allow the user to download such media directly to the user's local device.

When supported media is downloaded:

* The download is initiated by the user.
* The media is downloaded directly to the user's device.
* TheoLibre does not upload the downloaded media to TheoLibre servers.
* TheoLibre does not host or mirror downloaded media.
* TheoLibre does not provide downloaded media to other users.
* Downloaded media remains under the user's local control.
* TheoLibre does not bundle third-party media with its source code or application releases.

TheoLibre is not intended to provide a service for redistributing or sharing downloaded media.

Users are responsible for ensuring that their use of downloaded media complies with applicable copyrights, licenses, terms of use, and other legal requirements.

The JW.ORG Terms of Use expressly distinguish free, noncommercial applications designed to download electronic files such as MP4 from applications intended to collect, scrape, or harvest website content.

For the applicable terms, see:

## No Content Hosting or Redistribution

TheoLibre does not provide a content-hosting service for JW.ORG or JW Library materials.

The project does not intentionally:

* Host publications on TheoLibre servers
* Mirror JW.ORG content
* Proxy media through TheoLibre servers
* Redistribute downloaded videos or audio
* Provide a shared online media library
* Upload user publications or media to a central server
* Provide copyrighted publications through GitHub
* Provide a public repository of downloaded media

TheoLibre is intended to operate primarily as a **local desktop application**.

## No Web Scraping or Content Harvesting

TheoLibre is not intended to be a general-purpose web scraper or content-harvesting tool for JW.ORG.

The project does not provide functionality specifically designed to systematically collect, copy, extract, harvest, mirror, or scrape website content.

Downloading a media file explicitly referenced by a supported local publication is a different operation from providing a general-purpose website scraping or content-harvesting system.

TheoLibre does not provide a mechanism for bulk harvesting the JW.ORG website.

## Direct Media Downloads

When TheoLibre downloads a media resource, the application attempts to retrieve the resource from its referenced source rather than routing the media through a TheoLibre-controlled server.

TheoLibre does not operate a proxy, CDN, mirror, or media distribution service for third-party content.

The project does not intentionally bypass authentication, access controls, rate limits, DRM, or other technical restrictions imposed by a remote service.

## Building

Clone the repository:

```bash
git clone https://github.com/edurbs/theolibre.git
cd theolibre
```

Build the project with Maven:

```bash
./mvnw clean verify
```

If the Maven Wrapper is not yet included:

```bash
mvn clean verify
```
